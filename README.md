# Global Billionaires Tableau Dashboard

## Project Type
Academic Project | Baylor University

## Project Overview
Built an interactive Tableau dashboard to analyze global billionaire wealth distribution by industry, gender, age, geography, and economic indicators to uncover business and investment insights.

## Tools & Skills Used
- Tableau
- Data Visualization
- Dashboard Design
- Business Intelligence
- Exploratory Data Analysis (EDA)
- Interactive Reporting
- Data Storytelling

## Key Work Performed
- Built visualizations to analyze billionaire distribution across industries
- Examined gender disparity and wealth concentration
- Analyzed billionaire age and industry relationships
- Incorporated economic indicators such as GDP, CPI, and tax metrics
- Created interactive visual insights for business interpretation

## My Contribution
Designed visualizations, performed data analysis, interpreted trends, and developed interactive reporting insights using Tableau.
